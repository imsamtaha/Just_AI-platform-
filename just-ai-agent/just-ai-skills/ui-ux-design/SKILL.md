# JUST AI UI UX Design

## Workflow
1. Define user, task, context, and outcome.
2. Map the primary flow and information architecture.
3. Establish hierarchy, layout, responsive behavior, and states.
4. Reuse or define a coherent design system.
5. Check accessibility, keyboard interaction, and mobile behavior.

## Rules
- Design for task completion before decoration.
- Always define loading, empty, success, and error states.
- Prefer accessible native patterns where possible.
